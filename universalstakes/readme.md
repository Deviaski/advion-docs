# UniversalStakes Wiki

> **Start here:** New to the plugin? Read [Install the plugin](Installation.md), then follow [Create your first stake](First-Stake.md). You do not need coding experience.

UniversalStakes lets players enter timed competitions. They deposit an item, Vault money, or a custom item; the biggest contributors win configured rewards.

## A few words you will see often

- **Stake** — one competition, such as “Diamond Race”.
- **Round** — one timed run of that stake.
- **Stake ID** — the file name without `.yml`, for example `diamonds` from `diamonds.yml`.
- **Alias** — the short command for a stake, for example `/diamonds`.

Keep one test stake until you are comfortable. Once it works, copy its file to create more events.
