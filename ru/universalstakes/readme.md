# UniversalStakes Wiki

UniversalStakes превращает излишки предметов и денег на вашем сервере в **гонку в таблице лидеров**.
Игроки выбирают событие, вносят ресурсы, зарабатывают очки и поднимаются по доске. Когда таймер закончится,
лучшие игроки выигрывают настроенные вами призы. Все остальные могут получить утешительное вознаграждение или возврат средств.

Вам **не** нужен какой-либо опыт программирования для запуска этого плагина. Если вы можете редактировать текстовый файл `.yml`, вы
может запускать UniversalStakes.

## Общая картина (30-секундная версия)

1. Вы создаете **событие**, помещая небольшой файл `.yml` в папку плагина.
2. Мероприятие длится выбранное вами время (например, 1 час). Этот забег называется **раундом**.
3. Игроки открывают меню, выбирают ресурс и **вносят** его. Каждая депонированная единица имеет определенную ценность
   **точек**, которые вы установили. Очки определяют таблицу лидеров.
4. Когда таймер заканчивается, раунд **завершается**: лучшие игроки получают свои призы, а игроки, находящиеся рядом
   Верхний может получить утешительное вознаграждение или вернуть процент от своего депозита.
5. Призы безопасно ждут в `/stakes rewards`, пока игрок не заберет их — даже если они были офлайн.

Для полной версии с круглым жизненным циклом, макетом файла и тем, что происходит за кулисами,
прочитайте [Как это работает](How-It-Works.md).

## Слова, которые вы увидите много

Эти термины встречаются повсюду в этой вики. Просмотрите их один раз, и остальное обретет смысл.

| Срок | Значение |
| --- | --- |
| **Ставка** | Одно мероприятие/конкурс, например *Diamond Rush*. |
| **Идентификатор ставки** | Имя файла без `.yml`. `diamonds.yml` → идентификатор ставки `diamonds`. |
| **Круглый** | Однократное прохождение ставки. Ставка может состоять из нескольких раундов с течением времени. |
| **Псевдоним** | Короткая команда для ставки, например `/diamonds`. |
| **Источник вклада** | Один ресурс, который принимает ставка, со своей собственной валютой, стоимостью в баллах и ограничениями. Ставки могут иметь несколько. |
| **Очки** | Рейтинг лидеров. Одна депонированная единица дает значение `points` источника. |
| **Депозит** | Вкладывание ресурсов для получения очков. |
| **Снять** | Вывод ресурсов обратно во время активного раунда (если разрешено). |
| **Завершить** | В тот момент, когда раунд заканчивается, награды рассчитываются и сохраняются. |
| **Ожидание вознаграждения** | Приз ждет вас в `/stakes rewards`. |

## Одно правило, которое избавит вас от головной боли
> Всегда **проверяйте новое событие на тестовом сервере**, прежде чем открывать его для реальных игроков, и **создавайте резервные копии
> базу данных** перед обновлением плагина или изменением больших настроек. Эти две привычки предотвращают почти все
> Больная проблема в этой вики.
