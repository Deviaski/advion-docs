# Меню

> **Простое правило:** сначала измените текст, значки и историю. Не удаляйте раздел `dynamic-items`, если только
> вы намеренно хотите скрыть этот список.

Файлы меню находятся в `plugins/UniversalStakes/language/<locale>/menus/`. Отредактируйте их, затем запустите
`/stakes admin reload`, чтобы подать заявку.

## Семь файлов меню

| Файл | Что это показывает |
| --- | --- |
| `stakes-main.yml` | Все карточки событий (главное меню). |
| `stakes-menu.yml` | Одно выбранное событие: его призы и текущее место игрока. |
| `deposit-menu.yml` | Источники взносов; щелкните левой кнопкой мыши по вкладам, щелкните правой кнопкой мыши по выводу средств (если разрешено). |
| `stakes-history.yml` | История депозитов игрока. |
| `stakes-rewards.yml` | Ожидание наград с кнопкой «Заявить все». |
| `stakes-admin-logs.yml` | Завершенные раунды, для администраторов. |
| `stakes-admin-log-events.yml` | Неизменяемые финансовые события/награды на один раунд (административный аудит). |

## Простые визуальные изменения

Внутри любой кнопки вы можете изменить `title` (название меню), `name`, `lore`, `material` и `texture` (для
значки головы игрока). Затем `/stakes admin reload`. Для этого не нужно трогать макет.

---

## Понимание `pattern`

Каждое меню рисуется из `pattern`. В каждой строке содержится **девять** символов, разделенных пробелами. Символ указывает
либо к записи `buttons`, либо к записи `dynamic-items`. `.` — это пустой слот.
```yaml
pattern:
  - "+ + + + + + + + +"
  - "+ @ @ @ @ @ @ @ +"
buttons:
  '+':
    material: BLACK_STAINED_GLASS_PANE
    name: " "
dynamic-items:
  stakes:
    key: "@"
```
Здесь `+` — граница, а `@` заполнен карточками событий. Вы можете повторить символ столько раз, сколько
тебе нравится. Количество строк в `pattern` задает размер меню.

## Кнопки

Кнопка сопоставляет символ шаблона с элементом и дополнительными действиями:
```yaml
buttons:
  'X':
    material: IRON_DOOR
    name: "<red>Back"
    actions:
      left:
        - "sound: UI_BUTTON_CLICK 1.0 1.0"
        - "menu: stakes-main"
```
`actions.left` запускается при щелчке левой кнопкой мыши, `actions.right` при щелчке правой кнопкой мыши. Действия выполняются **сверху вниз**.

---

## Действия кнопок (полный список)

| Действие | Что он делает |
| --- | --- |
| `menu: stakes-main` | Откройте другое меню. Используйте `menu: stakes-menu {stake_id}`, чтобы передать ставку. |
| `sound: UI_BUTTON_CLICK 1.0 1.0` | Воспроизведите звук с дополнительной громкостью и высотой тона. |
| `close` | Закройте инвентарь. |
| `page: next` / `page: previous` | Перемещение по страницам динамического списка. |
| `invest: {stake_id}` | Откройте селектор вкладов этой ставки. |
| `contribution: {stake_id}\|{source_id}` | Подскажите сумму. Щелкните левой кнопкой мыши по вкладам; щелчок правой кнопкой мыши отменяется, когда `withdrawals-enabled: true`. |
| `claim` | Получите все ожидающие награды. |
| `claim: {reward_id}` | Получите одну конкретную награду. |
| `message: messages.someKey` | Отправьте сообщение, определенное в `messages.yml`. |
| `command: stakes` | Запустите команду **от имени игрока**. |
| `console: give %player% diamond 1` | Запустите команду **от консоли**. |
| `permission: some.node \| deny: messages.noPermission` | Остановите остальные действия, если у игрока не хватает узла. |
| `delay: 20` | Подождите это количество тактов, прежде чем запускать остальную часть цепочки действий. |

Токены `{...}` заполняются из контекста меню перед запуском действия.

> `console:` и команды вознаграждения выполняются с **правами консоли**. Редактировать меню должны только проверенные сотрудники.
> файлы. См. [База данных и безопасность](Database-and-Safety.md).

## Динамические разделы (автозаполняемые списки)

Запись `dynamic-items` заполняет свой символ шаблона автоматическим списком. У каждого есть `key` (
символ шаблона), и список автоматически разбивается на страницы.

| Название раздела | Заполнено |
| --- | --- |
| `stakes` | Карточки событий. |
| `prizes` | Один слот на каждый настроенный главный приз по открытой ставке. |
| `self` | Собственное место зрителя и вложенная сумма. |
| `contributions` | Источники вкладов в открытую ставку. |
| `history` | Записи истории депозитов зрителя. |
| `rewards` | Ожидаемые награды зрителя. |
| `audit-rounds` | Завершенные раунды (админ-меню). |
| `audit-events` | События за один пройденный раунд (админ-меню). |

Сохраните соответствующий раздел, если хотите, чтобы этот контент отображался. Все разделы с разбивкой на страницы имеют одинаковый
текущая страница; виджет с одним элементом, например `self`, остается видимым, пока просматривается больший список.

---

## Резервный вариант `empty`

Когда в динамическом списке нечего показывать, блок `empty` размещается в его `slot`:
```yaml
empty:
  slot: 22
  material: BARRIER
  name: "<red>No rewards yet"
  lore:
    - "<gray>Play in events and win prizes."
```

## Безопасность перезарядки

Прежде чем заменять живые меню, перезагрузите **проверку** каждого файла меню. Если в меню есть недопустимый
материала, макета, динамического поставщика, действия или ссылки на меню, перезагрузка **отклоняется** и
ранее работавшее меню остается активным. Консоль называет файл и поле. Проверки валидации
структура, а не безопасность команд — это остается вашей ответственностью.
