Настройки ставок

Используйте эту страницу, если у вас уже есть файл ставок и вы хотите разобраться в одной настройке. Для Для начала используйте Ваша первая ставка.

Идентификатор ставки — это имя файла без .yml. Используйте простые имена в нижнем регистре, например weekly-diamonds.yml. В файлах ставок используются ключи kebab-case (withdrawals-enabled, min-invest).

На этой странице описан каждый блок сверху вниз. Сами типы валют подробно описаны в Валюты и призы в Rewards.

Корневые настройки

Настройка Тип По умолчанию Значение
alias текст "" Короткая команда для этого события, например. diamonds включает /diamonds. Пусто = нет псевдонима. Уникальный; для добавления/изменения требуется перезагрузка.
permission текст "" Узел разрешения необходим для просмотра и присоединения. Пустой/отсутствует = общедоступный. Не генерируется автоматически; предоставь это себе.
withdrawals-enabled правда/ложь true Могут ли игроки щелкнуть правой кнопкой мыши, чтобы забрать ресурсы во время активного раунда? Перезарядка безопасна.

display — карточка события

Вот как событие выглядит в списке главного меню.

display:
  display-name: "Diamond Race"
  name: "<aqua>Diamond Race"
  lore:
    - "<gray>Deposit diamonds and reach first place!"
  material: DIAMOND
  model-data: 0
Поле Значение
display-name Понятное для человека имя, используемое в сообщениях, истории, наградах и заполнителях. Пробел возвращается к name.
name Название предмета, указанное на карточке. Поддерживает MiniMessage (<aqua>, <gold>…).
lore Строки под заголовком.
material Материал Minecraft, например. DIAMOND, PAPER, EMERALD.
model-data Данные пользовательской модели для пакетов ресурсов. Оставьте 0, если вы его не используете.

В истории карты могут использоваться встроенные токены, такие как {status}, {time_left} и {participants} — это предоставляются самим плагином и работают без PlaceholderAPI.

messages — запуск, остановка, напоминания

messages:
  started:
    - "{prefix}<green>{stake} has been started."
  stopped:
    - "{prefix}<green>{stake} has ended. Winner: {winner-player-1}!"
  reminder:
    interval: "5m"
    message:
      - "{prefix}<aqua>{stake}</aqua> is active! Time left: <yellow>{time_left}</yellow>"
Поле Когда оно будет отправлено
started Когда начинается раунд. Трансляция для онлайн-игроков, которые могут получить доступ к событию.
stopped Когда раунд завершается. Трансляция для онлайн-игроков, которые могут получить доступ к событию.
reminder.message Каждый reminder.interval, пока активен раунд, для игроков, имеющих право на участие в розыгрыше онлайн.

Используйте пустой список ([]) для любого из них, чтобы отключить это сообщение. reminder.interval должен быть положительная длительность, например 30s, 5m или 1h.

Заполнители доступны в сообщениях о ставках

{stake}, {stake_raw} (имя в виде обычного текста), {time_left}, {participants}, {total} (всего) баллов), {alias}. В stopped вы также получаете {winner-rank-1}, {winner-player-1}, {winner-points-1} … до вашего наивысшего настроенного высшего ранга.

Полный список и форматирование см. в разделе Сообщения и заполнители.

contributions — какой депозит вносят игроки

Для каждой ставки требуется хотя бы одна запись. Ключом карты является идентификатор источника (1–64 символа, должен начинаться с строчная буква или цифра, затем строчные буквы/цифры/_/-; с учетом регистра).

contributions:
  diamonds:
    display-name: "Diamonds"
    currency:
      type: ITEM
      material: DIAMOND
    points: 5
    display:
      material: DIAMOND
      name: "<aqua>Diamonds"
      lore:
        - "<gray>Deposited: {deposited}"
    limits:
      min-invest: 1
      max-invest: 64
      daily-limit: 256
Поле Значение
display-name Имя источника, используемое в истории, и заполнители призов, доступные как {<id>.display-name}.
currency Что это за ресурс. См. Валюты.
points Положительное целое число. Оценка = amount × points.
display Как выглядит источник в меню депозита (material, model-data, name, lore).
limits Лимиты депозитов для каждого игрока (см. ниже).

Источник lore может использовать {source_id}, {display-name}, {deposited}, {points-per-unit}, {min-invest}, {max-invest} и {daily-limit}.

Ограничения

Настройка Значение
min-invest Минимальный размер одного депозита. Должно быть положительным и ≤ max-invest.
max-invest Максимальный размер одного депозита. Должно быть положительным и ≥ min-invest.
daily-limit Максимальный чистый депозит в этот источник за серверный день. 0 = неограниченно. Если установлено, оно должно быть ≥ min-invest.

Вывод уменьшает чистую сумму, засчитываемую в дневной лимит, поэтому игроки могут внести депозит еще раз. после вывода.

Валюта, points и лимиты могут быть изменены только после завершения раунда ставок ENDED. Остановите Ставь и жди сначала доработки. См. Перезагрузка и перезапуск.

time — время раунда

Для длительности используйте d/h/m/s, например. 30m, 2h, 1d или 1h30m.

time:
  duration: "24h"
  restart-delay: "1h"
  auto-restart: true
Поле Значение
duration Как долго один раунд остается открытым. Должно быть больше нуля.
restart-delay Перезарядка после раунда заканчивается до начала следующего. Должно быть больше нуля.
auto-restart true = запускать первый раунд при запуске и автоматически запускать последующие раунды. false = новая ставка остается остановленной при запуске, а завершенная ставка остается остановленной до тех пор, пока сотрудники не запустят /stakes admin start. Активный раунд всегда возобновляется после перезапуска сервера, независимо от этой настройки.

Изменение time.* требует полной перезагрузки.

prizes — победители и утешение

Два блока: top (рейтинговые места) и others (утешительные уровни). Полная информация и примеры находятся в Награды.

prizes:
  top:
    1:
      material: NETHER_STAR
      name: "<gold>Winner"
      need-free-slots: 1
      rewards:
        - "give %player% diamond 64"
  others:
    1:
      type: COUNT
      amount: 10
      refund-percent: 50
      need-free-slots: 1
      rewards:
        - "give %player% emerald 10"

Правила, которые следует запомнить:

  • Ключи prizes.top являются конечными позициями, смежными, начиная с 1 (1, 2, 3…).

  • Ключи prizes.others представляют собой утешительные уровни, смежные, начиная с 1. Игрок получает не более одного уровень. Уровень 1 начинается сразу после победителей в рейтинге; уровень 2 начинается после игроков уровня 1 и т. д.

  • refund-percent — это 0–100, возвращается для каждого источника и округляется в меньшую сторону.

  • type: COUNT = фиксированное количество следующих игроков; type: PERCENT = процент от всех участников (amount, затем 0–100).

  • Каждая команда вознаграждения запускается как консоль. %player% / %player_name% станет именем победителя.

Ограничения безопасности (для всего плагина)

Они защищают арифметику базы данных и вознаграждают полезную нагрузку. Валидация отклоняет значения, которые их превышают — сократите вашу конфигурацию вместо того, чтобы обходить их.

Лимит Значение
Любая финансовая сумма (депозит, вывод, общая сумма, возврат) максимум 9,007,199,254,740,991
Сериализованная полезная нагрузка одного вознаграждения максимум 60,000 UTF-8 байт
Закодированный бюджет команд вознаграждения на блок вознаграждения 12,000 байт (по одной строке, без зарезервированного символа U+0001)
Импортированный снимок пользовательского элемента самое большее 32 KiB двоичный
