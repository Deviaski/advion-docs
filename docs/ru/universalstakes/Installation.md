# Установка

> **Вам потребуется:** Бумага версий с 1.20.4 по 26.2 и JAR-файл выпуска UniversalStakes. Используйте Java 21 на бумаге
> 1.20.4–1.21.11 или Java 25 на документе 26.1–26.2. Никогда не используйте JAR-файл, имя которого содержит `SNAPSHOT`, на
>живой сервер.

## Установка за 7 шагов

1. **Остановите** сервер Minecraft.
2. Поместите JAR-файл UniversalStakes в папку `plugins/` на сервере.
3. **Запустите** сервер один раз. UniversalStakes создает свои папки и файлы примеров.
4. **Остановите** сервер еще раз.
5. Откройте `plugins/UniversalStakes/`.
6. В `config.yml` выберите язык с помощью `locale: english` (или другого установленного пакета). Отредактируйте
   примеры событий в `language/english/stakes/`.
7. **Запустите** сервер и запустите `/stakes` в игре.

Вот и все. Два поставляемых примера события (*Coin Fever* и *Diamond Rush*) работают сразу же для
Депозиты на основе предметов и Хранилищ.

## Для первого запуска требуется Интернет (один раз)

JAR плагина **не** связывает библиотеки базы данных. При первом запуске Paper читает
`plugin.yml` и загружает HikariCP, Jdbi, драйвер SQLite, драйвер MySQL и их зависимости.
из Maven Central. Это происходит даже несмотря на то, что SQLite используется по умолчанию.

– Разрешите **исходящий HTTPS** для первого запуска.
- Для **автономного сервера** сначала запустите ту же версию на промежуточном сервере с подключением к Интернету.
  затем скопируйте полный кэш библиотеки Paper вместе с сервером. Если необходимая библиотека не может быть
  скачан, плагин не загружается — проверьте консоль Paper, прежде чем обвинять конфиг плагина.

## Дополнительные плагины

| Плагин | Вам это нужно? |
| --- | --- |
| **Vault** + плагин экономики | Только если у вас есть ставки, на которые вносятся виртуальные деньги (`type: VAULT`). |
| **PlaceholderAPI** | Требуется только для валют `PLACEHOLDER`. В противном случае необязательно — он также позволяет другим плагинам читать заполнители UniversalStakes. |

События на основе элементов не работают, если **ни один из них** не установлен.

## Краткий обзор папки

После первого запуска вы увидите:

| Путь | Цель |
| --- | --- |
| `config.yml` | Глобальные настройки: база данных, имена команд, язык, безопасность. |
| `currencies.yml` | Реестр для внешних валют PlaceholderAPI (поставляется с примерами PlayerPoints + ExcellentEconomy). |
| `data/data.db` | База данных SQLite (по умолчанию). |
| `imported-items/` | Снимки пользовательских элементов, созданные `/stakes admin importitem`. |
| `language/<locale>/` | Активный языковой пакет: `messages.yml`, `menus/`, `stakes/`. |

Полное объяснение каждого файла и того, как они сочетаются друг с другом, см.
[Как это работает](How-It-Works.md).

## Предоставьте доступ игрокам и персоналу

По умолчанию **никто** не имеет разрешений UniversalStakes.

- Подарите постоянным игрокам пакет **`universalstakes.use`**.
- Раздайте сотрудникам пакет **`universalstakes.admin`** (операторы получают его автоматически).

Полный список и доступ для каждой доли см. в разделе [Команды и разрешения](Commands-and-Permissions.md).
